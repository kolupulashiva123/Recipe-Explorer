Architecture

Mandatory Technology Stack

Designed with separation of concerns between an Angular single-page frontend and a Node/Express REST backend.

🅰️

Angular 18 Frontend

Built using modern standalone components, Angular Router with query parameter binding, reactive RxJS services, and HttpClient for asynchronous data streaming.

  • Standalone Components
  • Typed Data Models
  • Interactive Serving Scaler
  • Dynamic Filters & Sorts
🟢

Node.js & Express REST API

A decoupled Node.js and Express backend providing modular routes, controllers, request validation, and centralized error handling middleware.

  • RESTful Endpoints
  • Param & Query Validation
  • CORS Pre-Configured
  • Health Check Monitoring
📂

Local JavaScript Data Storage

All 30+ recipes and 12 categories are structured as clean, maintainable JavaScript modules (recipes.js and categories.js). Zero SQL or external database configuration needed.

  • Zero External DBs (No Mongo/SQL)
  • Zero Paid API Keys Required
  • 100% Offline Capability
  • Deterministic Sample Data
💾

Browser LocalStorage Persistence

Saved favorites are persisted locally on the client using HTML5 Web Storage API, guaranteeing that saved meals remain safely available across browser refreshes with no sign-in required.

  • No Authentication Barrier
  • Instant Reactive Updates
  • One-Click Clear & Toggle
  • Offline Accessible
Key Features

What Makes Recipe Explorer Special?

⚖️

Dynamic Serving Size Adjustment

Double, triple, or scale recipes down. Ingredient quantities recalculate proportionally in real-time so home cooks can shop and measure without doing mental arithmetic.

🔍

Multi-Dimensional Search & Filtering

Search recipes by name or ingredients, and narrow down dishes by cuisine, meal type (breakfast, lunch, dinner, dessert), dietary restrictions, and prep/cook duration.

🖨️

Kitchen-Friendly Print Mode

Dedicated print stylesheet strips away navigation, footers, and buttons, generating a crisp black-and-white recipe sheet ready for physical kitchen counters.

🎨

Warm Culinary Aesthetic

Warm orange, rich cream, fresh herb green, and crisp white typography with rounded cards, smooth micro-interactions, and mobile-first responsiveness.
